Creator Partnership Scout

An internal research tool operated by Amit Hoffman

Creator Partnership Scout helps one person decide which small YouTube creators to approach with a partnership offer. We build a digital product for a creator’s audience; the creator shares it once, and 70% of every sale is theirs.

The Tool has no public interface, no user accounts, and no users other than its operator. It is not distributed or sold.

Use of YouTube API Services

This application uses YouTube API Services. It reads only public data — channel statistics, public video metadata, and public comments — through the official YouTube Data API. It requests no user authorisation and accesses no private account data.

By using YouTube API Services this application is bound by the YouTube Terms of Service, and data handling is described in the Google Privacy Policy and in our own privacy policy below.
