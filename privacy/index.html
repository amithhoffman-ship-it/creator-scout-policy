Privacy Policy

Creator Partnership Scout · an internal tool operated by Amit Hoffman
Last updated 16 September 2026

This policy describes how Creator Partnership Scout (“the Tool”) handles data. The Tool is an internal research utility used by one person to identify YouTube creators who might be interested in a business partnership. It has no public interface, no user accounts, and no users other than its operator.

In short: the Tool reads publicly available YouTube data through the official YouTube Data API. It does not collect anything from you, because there is no “you” — there are no visitors, no sign-ups and no tracking. The only personal data involved is the public information creators have themselves chosen to publish on their channels.

Use of YouTube API Services

The Tool uses YouTube API Services. By extension, its operation is governed by:

  • the YouTube Terms of Service
  • the Google Privacy Policy

The Tool does not request authorisation from any YouTube user and does not access any private account data. It uses an API key only, and reads exclusively public resources. Because no user ever grants the Tool access, there is no access to revoke; anyone wishing to review or revoke third-party access to their own Google account can do so at Google security settings.

What data is accessed

Through the YouTube Data API, the Tool reads only public fields:

  • Channel title, handle, description, self-declared country, subscriber count, video count
  • Public video metadata: titles, descriptions, publication dates, view, like and comment counts
  • Public top-level comments, including the commenter’s public display name and public channel ID

The Tool also reads a channel’s public “About” page over ordinary HTTPS in order to see the links a creator has chosen to display there.

The Tool does not access private videos, private playlists, subscriber lists, analytics, messages, or any data requiring a user’s authorisation. It does not attempt to identify, profile, or track individual viewers.

Why this data is used

To decide whether a creator is a suitable partner and to write an accurate, specific message to them. In practice this means checking whether a channel is within a given size range, whether its audience is genuinely active, and whether that audience is repeatedly asking the creator for something they cannot currently provide.

Storage and retention

  • Data is stored in a local database on a single personal computer. It is not hosted, published, shared, sold, or transferred to any third party.
  • Stored YouTube data is refreshed or deleted on a 90-day cycle, in line with the YouTube API Services Developer Policies.
  • Comments retrieved are read internally by the operator only. They are never displayed publicly, republished, or used for any purpose other than assessing audience demand.
  • No YouTube content is embedded, rehosted, or redistributed.

Contacting creators

Where a creator has chosen to publish a business email address, the operator may write to them once with a partnership proposal. Every message identifies the sender by name, explains why they are being contacted, and can be replied to or ignored. A creator who asks not to be contacted again will not be contacted again, and their data will be removed from the database on request.

Advertising, analytics and third parties

The Tool shows no advertising, runs no analytics, sets no cookies, and integrates no third-party trackers. This page itself is a static document hosted on GitHub Pages; GitHub may log ordinary server request data as described in the GitHub Privacy Statement.

Children

The Tool is not directed at children and collects nothing from them. It reads only publicly published channel information.
