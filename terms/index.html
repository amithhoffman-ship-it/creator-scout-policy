1. Use of YouTube API Services

The Tool uses YouTube API Services. Its operation is governed by the YouTube Terms of Service and the YouTube API Services Developer Policies. Data handling by Google is described in the Google Privacy Policy.

2. What the Tool may do

  • Read public channel, video, and comment data through the official YouTube Data API using an API key.
  • Store that data locally for the sole purpose of assessing whether a creator is a suitable partner.
  • Contact a creator once, at a business address the creator has chosen to publish, with a partnership proposal.

3. What the Tool may not do

  • Access private user data, or request authorisation from any YouTube user.
  • Embed, rehost, republish, or redistribute YouTube content.
  • Sell, license, or transfer retrieved YouTube data to any third party.
  • Build profiles of individual viewers, or use data for advertising targeting.
  • Scrape youtube.com in place of the API for data the API provides.
  • Circumvent quota, whether by additional projects, additional keys, or any other means.

4. Data retention

Stored YouTube data is refreshed or deleted on a 90-day cycle, in line with the Developer Policies. A creator may request removal of their data at any time, and the request will be honoured.

5. Contacting creators

Outreach is sent once per creator, identifies the sender, states its purpose, and can be declined. A creator who asks not to be contacted again will not be contacted again.
